# Dependency advisories

Source: `pnpm audit` (GitHub Advisory Database via the npm registry), run 2026-10-09 against
`pnpm-lock.yaml`. The repository is **not** free of known advisories: four apply to installed
packages. None is fixed by a supported upgrade today, and no override or dependency change has been
made. Exposure below was checked by tracing which code loads each package; the production build's
file traces (`.next/server/**/*.nft.json`) and bundles contain none of the three packages.

## Disposition (accepted 2026-10-09)

The project owner accepted all four advisories for the local-only MVP release, based on the
exposure analysis above, and will monitor them. No overrides, release-candidate upgrades, or audit
suppressions were added, and the repository is not described as free of known vulnerabilities.

Reassess this disposition:

- before any public deployment;
- before any change that makes the affected functionality reachable (a MySQL datasource or Better
  Auth MySQL dialect, user-supplied input to Prisma configuration merging, or untrusted glob patterns
  in lint configuration); and
- when a stable Prisma release (8.x) or patched `braces` / `@next/eslint-plugin-next` release is
  available. Remediation options remain as listed in the table (`mysql2` ≥ 3.23.1 via upgrade or an
  approved override; `deepmerge-ts` ≥ 8.0.0 through a stable Prisma upgrade).
